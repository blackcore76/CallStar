<h1 align="center">통화서랍 (CallStar)</h1>

**통화녹음 중요도 구분 · 관리 앱** — 갤럭시 기본 통화녹음을 통화 종료 직후 별점으로 분류하고, 낮은 점수는 정리·삭제, 중요한 통화는 안전하게 백업합니다.

> ⚠️ 통화서랍은 **통화를 녹음하지 않습니다.** 스마트폰의 기본 통화녹음 기능이 저장한 파일을 읽어 **관리**만 합니다.

## 핵심 기능
- **통화 종료 직후 별점 팝업** — 판단이 선명한 그 순간에 ★중요 / △정리후보 / 즉시 삭제
- **목록 관리** — 재생(미리듣기)·재분류·필터(정리후보만)·일괄 처리·전체선택
- **중요 통화 자동 백업(프리미엄)** — ★중요로 표시하면 지정 폴더로 원본 복사(원본 유지)
- **라이트/다크 테마**
