## 긴 설명 (최대 4000자)
```
★ 통화가 끝난 직후, 바로 그 순간이 중요도를 아는 유일한 타이밍입니다.

통화서랍은 갤럭시 등 스마트폰의 기본 통화녹음 파일을 통화 종료 직후 별점으로 분류하고,
낮은 점수는 골라서 정리·삭제하고, 중요한 통화는 안전하게 백업하는 통화녹음 관리 앱입니다.

■ 통화서랍은 통화를 "녹음하지 않습니다"
통화서랍은 통화를 직접 녹음하지 않습니다. 스마트폰의 기본 통화녹음(자동 녹음) 기능이
이미 저장해 둔 파일을 읽어 "관리"만 합니다. 별도의 녹음 기능이나 접근성 권한을 사용하지 않습니다.

■ 이런 분께
· 통화녹음이 수백 개 쌓여 정리를 못 하고 있는 분
· 업무 전화, 주문 전화처럼 중요한 통화는 꼭 남기고 싶은 분
· 안부 전화 같은 일상 통화는 그때그때 지우고 싶은 분

■ 주요 기능
· 통화 종료 직후 별점 팝업 — ★중요 / △정리후보 / 즉시 삭제 / 나중에
· 목록에서 미리듣기(재생·구간 이동)로 내용 확인 후 분류
· "정리후보만 보기" 필터 + 전체선택으로 한 번에 정리
· 낮은 점수 파일 일괄 삭제 (안드로이드 시스템 삭제 확인)
· 날짜·시각·통화 길이 한눈에 · 라이트/다크 테마

■ 중요 통화 자동 백업 (프리미엄)
★중요로 표시하면 원본은 그대로 두고, 미리 지정해 둔 폴더로 녹음 파일이 자동 복사됩니다.
통화녹음이 정리되거나 사라져도 중요한 통화는 안전하게 보관됩니다.

■ 개인정보
모든 처리는 기기 안에서만 이루어집니다. 어떤 정보도 수집·전송하지 않으며, 인터넷 권한을 사용하지 않습니다.
개인정보처리방침: https://blackcore76.github.io/CallStar/privacy-policy.html

■ 권한 안내
· 전화 상태 — 통화 종료를 감지해 별점 팝업을 띄우기 위해 사용합니다.
· 오디오/미디어 읽기 — 통화녹음 파일 목록과 재생을 위해 사용합니다.
```
