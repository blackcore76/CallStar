# 통화서랍 — Play 스토어 등록 정보 (v1.0.0)

## 앱 이름 (제목 · 최대 30자)


## 짧은 설명 (최대 80자)
```
통화 끝나면 알림으로 중요도 표시 · 중요한 건 백업, 필요 없는 건 삭제 · 광고·수집 없음
```

## 긴 설명 (최대 4000자)
```
★ 통화가 끝난 직후, 바로 그 순간이 중요도를 아는 유일한 타이밍이에요.

통화서랍은 갤럭시 기본 통화녹음 파일을 통화 직후 "중요 / 정리후보"로 나누고,
중요한 통화는 따로 백업하고, 필요 없는 통화는 골라서 지우는 통화녹음 정리 앱이에요.

■ 녹음하지 않아요, 보내지 않아요
· 통화서랍은 통화를 직접 녹음하지 않아요. 스마트폰 기본 통화녹음이 저장한 파일을 정리만 해요.
· 인터넷 권한이 없어요. 녹음 파일과 분류 정보는 휴대폰 밖으로 나가지 않아요.
· 광고가 없고, 어떤 정보도 수집하지 않아요.

■ 이런 분께
· 통화녹음이 수백 개 쌓여 정리를 못 하고 있는 분
· 업무 전화, 주문 전화처럼 중요한 통화는 꼭 남기고 싶은 분
· 안부 전화 같은 일상 통화는 그때그때 지우고 싶은 분

■ 주요 기능
· 통화가 끝나면 알림으로 바로 표시 — ★중요 / △정리후보 / 🗑삭제
  잠금화면·알림창에 남아서, 나중에 폰을 볼 때 처리해도 돼요
· 표시 안 한 통화가 여러 건이면 알림 하나에 모아서 차례로 보여줘요
· 오늘 아직 정리 안 한 통화는 목록에서 테두리로 표시
· 목록에서 미리듣기(재생·구간 이동)로 내용을 확인하고 분류
· "정리후보만 보기" + 전체선택으로 한 번에 정리, 선택한 파일 용량 표시
· 삭제는 안드로이드 시스템 확인창을 거쳐 안전하게
· 라이트 / 다크 테마

■ 플러스 기능 (지금은 무료)
· 중요 통화 자동 백업 — ★중요로 표시하면 원본은 그대로 두고 지정한 폴더로 복사
· 자동 중요 표시 — 등록한 이름·번호와의 통화는 묻지 않고 ★중요로 표시
  (연락처에서 한 명씩 골라 등록, 연락처 전체에는 접근하지 않아요)
· 백업함 — 백업한 통화를 다시 들어보고, 이제 필요 없으면 원본까지 한 번에 정리

■ 권한 안내
· 전화 상태 — 통화가 끝난 것을 알아채기 위해 사용해요 (통화 내용·번호는 읽지 않아요)
· 오디오 읽기 — 통화녹음 파일 목록과 재생을 위해 사용해요
· 알림 — 통화 직후 중요도 표시 알림을 보여주기 위해 사용해요
· 다른 앱 위에 표시 (선택) — 알림 대신 즉시 팝업 방식을 고른 경우에만 사용해요

개인정보처리방침: https://blackcore76.github.io/CallStar/privacy-policy.html
```

## Play Console 데이터 보안 양식 (답변 초안)
- 앱이 사용자 데이터를 수집하거나 공유하나요? → **아니요**
  - 근거: 인터넷 권한 없음(최종 매니페스트 확인), 광고·분석 SDK 없음, 클라우드 자동 백업 꺼짐(allowBackup=false)
- 데이터 암호화 전송 → 해당 없음(전송 없음)
- 데이터 삭제 요청 방법 → 앱 삭제 시 앱 내 데이터(분류 정보·설정) 모두 삭제
- 광고 포함 → **아니요**
